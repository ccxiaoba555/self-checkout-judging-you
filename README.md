A smug self-checkout machine says the quiet part out loud — one line, 129 characters, zero mercy:

> Twelve yoghurts, one cucumber, zero eye contact. Please place your shame in the bagging area — I've already told the other tills.

The program writes that single line to `/output/entry.txt` for make.fun's "The Self-Checkout Is Judging You" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
